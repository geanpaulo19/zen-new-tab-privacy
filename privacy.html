Zen New Tab - Privacy Policy

Effective Date: January 15, 2026

1. Introduction

Zen New Tab is a minimal Chrome extension providing time, date, daily quotes, beautiful backgrounds, a search bar with multiple engines, and subtle weather information. This Privacy Policy explains how data is handled.

2. Data Collection

This extension does not collect personal data. All features operate locally in the browser.

3. API Usage

The extension fetches data from the following sources:

  • Unsplash, Pexels & Lorem Picsum (via Vercel proxy): Retrieves background images.
  • ZenQuotes & TypeFit: Retrieves daily motivational quotes.
  • DummyJSON, FreeAPI, Quotes-DB: Additional sources for quotes.
  • Open-Meteo: Fetches current weather using approximate location (geolocation).

All requests are anonymous and no personal information is transmitted to these APIs.

4. Geolocation

Geolocation is used only to fetch the current weather at the device's location. Location is not stored, shared, or transmitted elsewhere.

5. Local Storage

The extension stores minimal temporary data locally:

  • Cached background images to reduce API calls
  • Time format preference (12/24-hour)
  • Preferred search engine
  • Cached weather data (optional, to avoid repeated API calls)

All stored data remains on the device and is never sent externally.

6. Third-Party Links

Background image credits may link to Unsplash or Pexels photographer pages. See their Unsplash privacy policy and Pexels privacy policy for more information.

7. No Tracking

The extension does not use analytics, tracking, or advertising. All features operate locally on the device.

8. Changes to This Policy

This policy may be updated from time to time. When the extension is updated, review this page to stay informed.

9. Contact
